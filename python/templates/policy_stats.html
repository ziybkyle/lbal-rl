符号统计 · 交租桶

口径 / 图例说明（点开）
口径：交租桶 = 「第几次交租前」的租金档位（state.rent 的取值），桶与桶互不重叠—— 每个名字、每局只在它首次入手的那一桶里计一次，因此各桶可以直接横向比较，后一桶不再包含前一桶。 入手：符号/物品 = 首次出现在 board / inventory / items（含开局自带）； 精华 = 首次出现在 state.essences（持有），用到物品上后转入 destroyedItems。 物品整体前移一档：选物品发生在交租之前，rent=R 选到的物品记在 R 的前一档，与符号表同列对齐。 两个指标：终局胜率 = 该桶内这些局的胜率；本桶选择率 = 该桶内 选择次数 / 出现次数 （一次选卡屏算一次出现，跳过也算）。两者都按样本量分档显示。
