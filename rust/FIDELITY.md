# 当前规则与验证范围

当前规则：`2026-11-09-prespin-overflow-rent-offer-v15`。本页记录相对上一版公开提交 `69056b4` 的主要修复及当前验证边界。

## 结算和成长

- 消除和移除分别进入各自历史池，按对应的触发规则处理。怪异生物使用两个历史池的相关符号数量；潜水员、地质学家等的成长则按实例计算。
- 珍珠与潜水员、地质学家相邻时，两个效果都能获得应有的加成。香蕉同时喂食猴子和水果女士也有回归覆盖。
- 生成物按事件顺序检查空格。肥皂生成泡泡时不能抢占稍后才腾出的格子；满盘的椰子、矿石、骨灰瓮等生成链会区分当转上场和留到以后。新上场的符号可以触发本转适用的相邻效果。
- 修正满盘时开转前加入无用符号的时机、矿石和骨灰瓮的随机调用顺序、超出 20 格时的转轮落位，以及被吃符号的临时收益结算。
- 兔子和葡萄酒成熟只结算一次；箭头不放大负收益。鸡蛋成长与煎锅同时触发时，成长为小鸡优先。

## 候选、物品和交租

- 修正信用卡及精华的实际候选容量；重掷保留当前符号候选的品质、数量与限制，物品和精华不能重掷。交租奖励先于相应的普通额外候选。
- 同花、系绳硬币、粘毛滚筒等在旋转前按当前启用状态处理，移除的符号不再参与本次上场。物品和精华可对同一批符号分别结算收益，符号只移除一次。
- 精华按实际触发事件计数。修正重掷精华、时光机精华等的充能和消耗，冰棒重置适用精华的进度。
- 管理模式下，交租失败前可以使用存钱罐、脏话罐、咖啡或恶魔的交易，再按新余额确认；舒适枕头可选择使用或继续。有效动作由规则和动作掩码共同约束。

## 房东战和诊断

- 小字按伤害进度抽取，保留待生效与已生效状态，并记录动态目标。修正抽取顺序、无适用目标时的处理及部分限制对收益和操作的影响。
- Python 观测区分物品启用状态、存储金币、进度和剩余次数，并按符号提供消除/移除数量。候选可读取当前开启状态下的旋转前移除及固定收益。
- 结算明细按需开启；读取观测及诊断不推进随机数。相同局面的多个候选共用同一份旋转前规则计算。
