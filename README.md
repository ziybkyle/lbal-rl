# 幸运房东 Rust 规则模拟器

作者：群友镜中人

[中文](README.md) | [English](README.en.md)

这是《Luck be a Landlord》（幸运房东）的无界面规则模拟器，适合批量跑局、策略评估和强化学习。当前规则版本为 `2026-11-09-prespin-overflow-rent-offer-v15`，以进阶 20 为主，包含 5×4 棋盘、交租、符号和物品选择、精华、代币，以及 1500 生命的房东战。提供 Rust 命令行、Python 绑定和带动作掩码的环境。

## 相较上一版的主要修复

- **旋转与连锁结算**：区分消除和移除，分别记录符号池。修正同一符号被多个相邻效果同时处理、生成物进入空格或储物间的时机，以及矿石、骨灰瓮、肥皂、椰子等连锁中的收益和随机数顺序。兔子和葡萄酒的成熟加成只结算一次。
- **候选与代币**：信用卡和信用卡精华可提供 20 或 30 个符号候选。重掷仅适用于符号，保留当前奖励的品质保证与候选限制。修正冰冻披萨额外候选与交租奖励的先后顺序。
- **物品、精华与交租**：修正旋转前移除符号并兑现的效果、精华充能与消耗、物品开关，以及余额不足时使用存钱罐、脏话罐、咖啡或恶魔的交易后重新检查租金。舒适枕头和精华可在适用时选择使用。
- **房东战与对拍**：修正小字抽取、目标选择和生效时机。Python 可读取条款、物品进度、分类消除/移除池和候选的旋转前效果，也可按需开启每转结算诊断。相同种子和操作便于复现；与原版仍有未覆盖的差异。

具体修复、验证范围和复现方法见 [规则保真度](rust/FIDELITY.md)。

## 快速开始

游戏原始数据需自行准备：把符号、物品、精华和小字的 JSON 放在 `game/JSON`，或通过 `LBAL_DATA_DIR` / `--data-dir` 指定目录。构建及 Python 接入见 [Rust 使用说明](rust/README.md)。

```bash
cd rust
cargo test --release --workspace
cargo run --release -p lbal_cli -- --games 10000 --seed 42 --threads 20 --hist
```

本版在 Windows、i7-12700F、release 构建下，用内置手工策略跑了种子 42–10041 的 **10,000 局**：**645 胜（6.45%）**，平均交租 **6.51 次**、旋转 **49.8 次**、终局储物间 **25.5 个符号**。20 线程约用 **3.9 秒**（约 **2,567 局/秒**）。这是当前手工策略的模拟结果；批量模拟吞吐不等于神经网络训练速度。

提交问题时请附规则版本、种子、操作顺序和首次差异，便于按局面核查。
