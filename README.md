# lbal-rl · 幸运房东模拟与强化学习

[中文](README.md) · [English](README.en.md) · [下载模型](https://github.com/ziybkyle/lbal-rl/releases/tag/scratch-142k)

`lbal-rl` 是《幸运房东》（Luck be a Landlord）的进阶 20 模拟与训练项目。Rust 模拟器负责每次旋转、候选、交租和房东战的结算。Python 训练面板让策略在模拟器里反复游玩，通过 PPO 学习，并用固定种子评估保存后的模型。训练和评估可在 CPU 上本地完成。

## 当前 Rust 规则

- **旋转与连锁**区分消除和移除，分别记录符号池。修正多符号对同一目标的效果、新符号落位、矿石、骨灰瓮、肥皂和椰子的结算，以及兔子和葡萄酒的一次性成熟加成。
- **候选与代币**支持信用卡和精华提供 20 或 30 个符号候选。重掷保留原符号奖励的品质保证；物品与精华候选没有重掷动作。修正额外候选与交租奖励的顺序。
- **物品与交租**修正旋转前移除兑现、精华充能和消耗、物品开关，以及使用急救物品后重新检查租金。舒适枕头及精华有可选的使用时机。
- **房东战与复现**修正小字条款的抽取、目标及生效时机。观测包含条款、物品进度、分类符号池与候选的旋转前效果。原版对拍覆盖了已记录的种子和结算路径，其他路径仍可能有差异。[规则核对记录](rust/FIDELITY.md)

内置手工策略使用种子 `42` 到 `10041` 模拟 10,000 局，通关 512 局（5.12%），平均交租 6.73 次。本机 20 线程的 Rust release 构建约用 3.9 秒。PPO 训练另有网络采样、参数更新与写盘开销。[复现命令](rust/README.md#批量模拟与复现)

## 代码与数据

| 路径 | 内容 |
| --- | --- |
| `rust/` | 规则核心、批量模拟命令和 Python 绑定 |
| `python/training_ui.py` | 训练、评估、走势图和统计入口 |
| `python/train_fresh_rules.py` | 新建或续训 PPO，保存模型与逐局数据 |
| `python/candidate_policy.py` | 候选评分网络与动作掩码策略 |
| `python/training_analytics.py` | 从逐局日志生成可排序的离线 HTML 报表 |
| `data/` | 策略数据、规则特征和发布检查点清单 |

反馈规则差异时请附模拟器版本、种子类型、动作顺序和首次出现差异的旋转。反馈训练结果时请附模型保存点、奖励配置、评估种子与局数。
