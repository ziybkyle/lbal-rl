[项目首页](../README.md) · [English](METHOD.en.md) · [训练面板](TRAINING.zh-CN.md) · [统计说明](STATISTICS.zh-CN.md)

## 一局游戏和一次训练更新

研究目标是在进阶 20 打败房东。玩家通过旋转赚钱，从候选中选择符号、物品和精华，按期支付房租。前 12 次房租最高为 777。进入房东战后，赚取金币会削减房东的 1,500 点生命，期间仍需支付后续房租。棋盘只有 20 格。储物间超过 20 个符号后，每次旋转只有一部分能上场。

1. Rust 返回当前局面以及合法动作。策略网络给动作打分，训练时按分布抽样，以便探索不同选法。
2. 模拟器执行动作，返回新局面、训练奖赏及是否结束。一局结束就记录结果并进入下一个训练种子。
3. 每收集完整的 512 个环境动作，PPO 用这些经历更新策略网络和价值网络。512 个动作可以来自多局，也可能跨过某局的中段。
4. 到达保存边界时，面板保存权重、优化器和统计。该阶段最后一个未收满的采样批次留在本段的采样计数中，下一次续训会重新开始收集批次。

策略网络学习选择哪些动作。价值网络估计在当前奖励方案下，从某个局面继续玩能获得的累计分数，用于给 PPO 提供优势估计。训练中每一批的模型会继续影响后续选牌。固定种子评估使用保存后的同一个模型。

## 模型能看见什么

| 输入 | 举例 |
| --- | --- |
| 经济与阶段 | 金币、下次租金、剩余旋转、代币、奖励阶段、房东血量 |
| 候选与规则特征 | 符号身份、品质、基础值、规则引用、成长所需旋转数、旋转前兑现 |
| 储物间 | 已有符号的身份、基础值、已累计的收益或进度，如煤炭的成长计数 |
| 物品与精华 | 持有及启用状态、剩余进度、存款、可兑现金额 |
| 房东条款与历史池 | 各条款的目标、按种类统计的已消除及已移除符号 |

同类候选共享评分网络，候选位置和其身份都可区分。合法动作由模拟器掩码限定。常见动作包括旋转、选择、跳过、重掷符号、移除符号，以及按配置开关或使用物品。精华和物品候选不具备重掷权限。煤炭的成长时间等规则特征可以帮助学习，模型仍要通过经历学到这些信息对通关的价值。

## 递增交租奖励（方案二）

| 事件 | 默认分数 |
| --- | --- |
| 支付前 12 次租金 | 第 `k` 次给 `0.5 + (k−1)/11`，从 0.5 分递增至 1.5 分，共 12 分 |
| 正常失败 | −3 分 |
| 击败房东 | +20 分 |

超过动作上限的对局会单独标记为截断。面板可以调整各次交租、失败、通关和开关物品的分数。面板填写原始分数，传给 PPO 的奖励统一除以 20。[奖励代码](../python/reward_schemes.py)

## 可选训练设置

- **指定内容练习**让指定比例的局在开局或交租后获得某个符号、物品或精华。用于观察模型接触更多相关局面后的行为。
- **储物间超额扣分**在储物间继续扩张时，按自定义门槛、衰减和上限记入训练奖励。

评估使用正常开局和保存时的动作权限。发布检查点从随机权重开始，累计 142,000 局都使用递增交租奖励，其中 2,000 局使用了实验性的探索偏置。最后阶段采用正常开局、标准探索、零开关奖赏，并按允许列表限制可主动开关的物品及精华。[准确配置和允许列表](../data/published_scratch_142k.json)

## 评估与可复现性

- 默认面板评估从 `1900000000` 连续取种子。选同样局数就使用同一批开局，方便比较不同保存点。训练使用独立且互不重叠的种子区间。
- 每次评估冻结参数、在合法动作中取最高分。训练中会抽样探索且参数会更新，因此两种通关率分别报告。固定评估可降低对比噪音，长期反复用同一批种子挑模型时，额外留出新种子可以验证泛化。
- 胜率以有效对局为分母。每局达到 2,000 动作上限时标记截断。报告同时保留平均交租、通关数和截断数，便于核对样本。
- 复现实验请保存游戏数据版本、模拟器版本、模型哈希、种子区间、奖励、动作权限和练习配置。现有检查点以 CPU 版本的 PyTorch 和 SB3 保存。

| 发布模型的 PPO 参数 | 数值 |
| --- | --- |
| 算法 | SB3-Contrib MaskablePPO，单环境采样 |
| 采样批次、优化小批次 | 512 动作、256 样本 |
| 最大优化轮数、学习率 | 10、0.0003 |
| 折扣 `γ`、GAE `λ` | 1、0.95 |
| 熵系数、目标 KL | 0.01、0.05 |

每局的计算量随走到的旋转和决策次数变化。Rust 批量手工策略的速度可用于测模拟器吞吐，PPO 实验速度从面板运行进度查看。[设置与操作](TRAINING.zh-CN.md)
