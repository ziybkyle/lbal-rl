# 统计和报表怎么读

[项目首页](../README.md) · [English](STATISTICS.en.md) · [训练面板](TRAINING.zh-CN.md) · [训练方法](METHOD.zh-CN.md)

## 从面板找到数据

| 想查什么 | 在哪里看 |
| --- | --- |
| 模型最近打得怎么样 | **走势图**。上排是固定种子评估，下排是训练探索。训练可看全部、最近 1 万或最近 5 万局，也可切换 1,000、2,000、5,000、10,000 局统计窗口。 |
| 哪一次续训更好 | **结果对比**。每个单元格的 `A / B` 表示平均成功交租 `A` 次和通关率 `B`。可在表头设置中选择列。持续训练的表格按 10,000 局分组，磁盘仍保留每次阶段保存。 |
| 常死在哪一关，牌组多大 | **死亡与牌组**。切换训练探索或历次模型评估，选择最近窗口或全部。评估模式可选具体一批，对比上一次评估。 |
| 哪些候选最常选 | **训练 → 浏览器分析**，选择最新 1,000 局评估、最新 1,000 局训练探索或自定义累计范围。可切换符号、物品、精华，按稀有度筛选，点表头排序或导出 CSV。 |
| 某一局的种子和操作 | **逐局记录**，或者打开 HTML 排名下方的逐局表。评估报告可点进候选和操作明细。原始动作编号存于日志。 |

训练探索数据来自会尝试动作且持续更新的模型。评估数据来自固定权重和固定种子。两类数据各自算胜率，适合回答不同问题。比较保存点时，优先看相同种子和局数的评估。排查学习过程时，查看训练的滚动曲线和逐局记录。

## 通关、交租与牌组

- **通关率**是胜局数除以有效对局数。达到动作上限的截断局单独列出。运行进度和逐局汇总的平均交租使用该窗口内已记录的局。
- **失败时已成功交租 5 次**包括交完第 5 次租后、交完第 6 次租前结束的对局。例如下一次旋转余额已为负导致失败，也会落在这一组。房东战内失败归在已交 12 次一组。
- **终局牌组**是结束时储物间的符号总数，通关和失败分别取平均。图表同时给出有记录的局数。历史缺字段时按未知处理。

## 候选排名的分母

以煤炭为例，表里三个抓取率口径各有用途。

| 列 | 计算方式 |
| --- | --- |
| 总体选择率 | 至少选过一次煤炭的局数 ÷ 至少出现过一次煤炭候选的局数 |
| 首次选择率 | 每局第一次看到煤炭候选就选它的局数 ÷ 见过煤炭候选的局数 |
| 本交租区间选择率 | 此区间选煤炭的次数 ÷ 此区间煤炭出现的次数，同一局可能出现多次 |
| 持有后终局胜率 | 曾经持有煤炭的胜局 ÷ 曾经持有煤炭的有效局，包含获得后被消耗的情况 |

跳过或重掷的原候选算一次出现。重掷刷出的新候选另计。租金 25 支付成功后立即出现的符号、物品与精华奖励，以及该奖励的重掷，都归到 **交租 25 前**。后续旋转的候选进入 **交租 25～50**。归类以实际奖励阶段为准，普通阶段使用物品产生的候选留在当前区间。

读排名时同时看分子、分母、阶段和品质。某个符号的持有胜率还受成型牌组、其他物品以及能否活到该阶段影响。这些统计适合发现可进一步核对的行为，因果效果需要额外对照。

## 本地保存的文件

| 文件或目录 | 用途 |
| --- | --- |
| `runs/current_rules_training/<规则版本>/` | 每次阶段保存的模型与逐局数据 |
| `model_final.zip` | 阶段权重和优化器，可作续训起点 |
| `manifest.json`、`summary.json` | 规则、奖励、设置、父阶段、种子区间与结果汇总 |
| `training_games.jsonl` | 每局结局、种子、交租、旋转、牌组、终局代币和操作次数 |
| `training_decisions.jsonl.gz` | 候选、实际选择、持有历史和动作顺序，可按局号与汇总关联 |
| `*_games.jsonl`、评估报告 | 固定种子评估的逐局记录。手动评估另存于 `evaluations/` |
| `analyses/` | 从已有日志生成的离线 HTML 和数据覆盖说明 |

训练默认使用精简记录。每局结束后立刻写入，已结束的局可在训练中分析。复现某局时需要同版模拟器、游戏数据、种子和 `action_ids`。指定内容练习的局还要按记录应用赠送。需要逐步状态时可在命令行训练加 `--full-history`，文件体积及运行开销会增加。[逐局字段和完整过程格式](../EPISODE_HISTORY_SCHEMA.md)

从 GitHub 导入的 142,000 局模型含权重和训练设置。自定义训练统计的起点是本地续训后第一局，例如第 142,001 局。对发布模型做单独评估后，即可查看这次评估的候选和逐局统计。

## 从命令行生成报表

在项目目录将 `runs/my-continuation` 替换为你的保存点路径。生成分析时只读取已有日志。

```powershell
$py = ".\.venv\Scripts\python.exe"
& $py python/training_analytics.py runs/my-continuation --mode evaluation
& $py python/training_analytics.py runs/my-continuation --mode training
& $py python/training_analytics.py runs/my-continuation --mode custom --first 142001 --last 143000
```

`evaluation` 读取所选分支最近保存的评估，最多显示 1,000 局。`training` 读取最近 1,000 局训练记录，`custom` 的起止局数均包含在结果中。程序打印 `分析.html` 的路径。用浏览器打开即可使用筛选和排序。
